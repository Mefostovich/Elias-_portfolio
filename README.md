# Elias-_portfolio
# 🏪 Retail Sales Data Pipeline

## Project Overview
End-to-end data pipeline para análisis de ventas minoristas usando **Databricks**, **Power BI**, y **Python**. Implementa arquitectura Medallón (Bronze-Silver-Gold) con rigurosas reglas de calidad de datos.

## Tech Stack
- **Lakehouse**: Databricks + Delta Lake
- **ETL**: PySpark
- **BI**: Power BI
- **Automation**: Python (pandas, openpyxl)
- **Governance**: Data Quality Rules, Lineage Tracking
